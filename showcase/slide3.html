Cheat sheet

Which RAG, when?

Start simple and measure. Add complexity only where the baseline fails.
Just getting started / need a benchmarkNaive
Exact terms: product codes, IDs, error codesHybrid
Vague or chatty user questionsAdvanced · Multi-Query
Short questions, very different doc wordingHyDE
Chunks mean nothing on their own ("it", "the plan")Contextual · Parent-Doc
Follow-up questions in a chatConversational
Hallucinations are expensiveCorrective · Self-RAG
Mixed simple + complex trafficAdaptive
"Who designed the thing that X uses?"Graph · Agentic
Users must verify every claimCitation
Rule of thumb: fix retrieval before touching the prompt or the model. If the right chunk never reaches the LLM, no amount of prompting can save the answer.
